第一部分 · Python 基础

1. Python 及其数学库（一）

学习目标：搭建 Python 环境，掌握基础语法，认识 NumPy。

核心知识点

  • 环境搭建：推荐使用 Anaconda 或 Miniconda 管理 Python 环境，避免系统环境污染。
  • Jupyter Notebook：交互式编程，适合数据探索与学习记录。
  • NumPy 简介：Python 科学计算的基石，提供高性能的多维数组对象 ndarray。
import numpy as np
arr = np.array([1, 2, 3, 4])
print(arr, arr.shape, arr.dtype)

记忆要点

  • ndarray 是 NumPy 的核心，所有元素类型一致，内存连续，运算比原生 list 快几个数量级。

2. Python 及其数学库（二）

学习目标：掌握 NumPy 常用操作与广播机制。

核心知识点

  • 数组创建：np.zeros、np.ones、np.arange、np.linspace、np.random.rand。
  • 索引与切片：支持整数索引、切片、布尔索引、花式索引。
  • 广播机制（Broadcasting）：形状不同的数组在满足一定规则时可自动扩展运算。
a = np.array([[1, 2, 3], [4, 5, 6]])   # shape (2,3)
b = np.array([10, 20, 30])             # shape (3,)
print(a + b)  # 广播：b 自动扩展为 (2,3)

记忆要点

  • 广播规则：从末尾维度对齐，维度相同或其中一个为 1 即可广播。

3. Python 及其数学库（三）

学习目标：掌握矩阵运算与线性代数基础。

核心知识点

  • 矩阵乘法：np.dot 或 @ 运算符，注意与逐元素乘法 * 的区别。
  • 转置与逆：arr.T、np.linalg.inv。
  • 特征值与特征向量：np.linalg.eig，是 PCA、谱聚类等算法的基础。
A = np.array([[1, 2], [3, 4]])
B = np.array([[5, 6], [7, 8]])
print(A @ B)              # 矩阵乘法
print(A * B)              # 逐元素乘法
print(np.linalg.inv(A))   # 逆矩阵

记忆要点

  • @（或 dot）是矩阵乘法，* 是逐元素乘法，二者极易混淆，务必区分。

4. 数据清洗和特征选择

学习目标：理解数据预处理是机器学习成败的关键。

核心知识点

  • 缺失值处理：删除、填充（均值/中位数/众数）、插值。
  • 异常值检测：3σ 原则、箱线图（IQR）。
  • 特征缩放：标准化（Z-score）与归一化（Min-Max）。
  • 特征选择：过滤法（方差、相关系数）、包裹法、嵌入法。
from sklearn.preprocessing import StandardScaler
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)  # 标准化，均值0方差1

记忆要点

  • 垃圾进，垃圾出：数据质量直接决定模型上限，特征工程往往比调参更重要。

第二部分 · 机器学习经典算法

5. 多元回归和 Logistic 回归

学习目标：掌握监督学习中回归与分类的两大基础模型。

核心知识点

  • 线性回归：y = w·x + b，最小化均方误差（MSE）。
  • 多元回归：多个特征，用正规方程或梯度下降求解。
  • Logistic 回归：虽是"回归"之名，实为分类模型，输出概率。

<br /> \text{sigmoid}(z) = \frac{1}{1 + e^{-z}}<br />

  • 损失函数：交叉熵（Cross-Entropy），而非 MSE。

记忆要点

  • 线性回归解决回归问题，Logistic 回归解决二分类问题，二者不要混淆。
  • Logistic 回归通过 sigmoid 把线性输出压缩到 (0,1) 概率区间。

6. 决策树和随机森林

学习目标：掌握基于树的可解释模型与集成学习。

核心知识点

  • 决策树：通过递归划分特征空间，用信息增益 / 信息增益比 / 基尼指数选择分裂点。
  • 信息熵：H = -Σ p·log(p)，衡量不确定性。
  • 随机森林：Bagging + 随机特征选择，多棵决策树投票。
from sklearn.ensemble import RandomForestClassifier
rf = RandomForestClassifier(n_estimators=100)
rf.fit(X_train, y_train)

记忆要点

  • 决策树易过拟合，随机森林通过"样本采样 + 特征采样"的双重随机降低方差。
  • 随机森林可输出特征重要性，常用于特征选择。

7. SVM（支持向量机）

学习目标：理解最大间隔分类器与核技巧。

核心知识点

  • 核心思想：找一个超平面，使两类样本的间隔（margin）最大。
  • 支持向量：离超平面最近、决定超平面位置的那些样本点。
  • 核技巧（Kernel Trick）：将低维线性不可分数据映射到高维，使之线性可分。常用 RBF 核。

记忆要点

  • SVM 适合小样本、高维数据；对特征缩放敏感，务必先标准化。
  • 线性不可分时用核函数（RBF 最常用），本质是隐式高维映射。

8. 聚类

学习目标：掌握无监督学习的代表算法。

核心知识点

  • K-Means：随机选 K 个中心，迭代"分配样本→更新中心"直到收敛。
  • K 值选择：肘部法则（Elbow Method）、轮廓系数（Silhouette）。
  • 层次聚类：凝聚法/分裂法，用树状图（Dendrogram）展示。
from sklearn.cluster import KMeans
km = KMeans(n_clusters=3)
km.fit(X)
labels = km.labels_

记忆要点

  • 聚类是无监督学习，没有标签；K-Means 对初始中心和 K 值敏感。

9. EM 算法

学习目标：理解含隐变量模型的参数估计方法。

核心知识点

  • EM = 期望最大化（Expectation-Maximization），用于含隐变量的模型（如 GMM）。
  • E 步：根据当前参数，估计隐变量的期望（后验概率）。
  • M 步：固定隐变量，最大化似然更新参数。
  • 两步骤反复迭代，保证似然单调不减。

记忆要点

  • EM 用于"数据不完整 / 有隐变量"的场景，GMM（高斯混合模型）是其经典应用。

10. 隐马尔科夫模型 HMM

学习目标：理解序列数据的概率图模型。

核心知识点

  • HMM 三要素：初始状态概率 π、状态转移矩阵 A、观测概率矩阵 B。
  • 三个基本问题：
  • 评估问题 → 前向/后向算法
  • 解码问题 → Viterbi 算法
  • 学习问题 → Baum-Welch（EM 的特例）
  • 应用：词性标注、语音识别、中文分词。

记忆要点

  • HMM 假设"当前状态只依赖上一状态"（马尔科夫性），观测只依赖当前状态。

11. 主题模型 LDA

学习目标：理解文本主题挖掘的无监督模型。

核心知识点

  • LDA（Latent Dirichlet Allocation）：假设每篇文档是多个主题的混合，每个主题是词的概率分布。
  • 核心思想：从"文档-词"矩阵中挖掘隐含的"文档-主题-词"三层结构。
  • 超参数：α（文档-主题先验）、β（主题-词先验）。
  • 应用：文本聚类、推荐系统、舆情分析。

记忆要点

  • LDA 是生成式概率模型，通过 Gibbs 采样或变分推断求解。
  • 与 HMM 区别：LDA 处理"词袋"，不考虑词序。

第三部分 · 深度学习 CNN

12. 卷积神经网络 CNN（一）

学习目标：理解卷积的核心概念与动机。

核心知识点

  • 卷积运算：用一个滤波器（卷积核）在图像上滑动，提取局部特征。
  • 三大特性：局部连接、权值共享、平移不变性。
  • 卷积核：不同核提取不同特征（边缘、纹理、形状等）。

记忆要点

  • CNN 相对全连接网络的核心优势：参数大幅减少 + 提取空间局部特征。

13. 卷积神经网络 CNN（二）

学习目标：掌握 CNN 的完整结构与经典网络。

核心知识点

  • 典型结构：卷积层 → 激活层（ReLU）→ 池化层 → ... → 全连接层 → softmax。
  • 池化（Pooling）：最大池化 / 平均池化，降低尺寸、增强鲁棒性。
  • 经典网络：LeNet → AlexNet → VGG → ResNet → DenseNet。

记忆要点

  • 池化不引入参数，作用是降维 + 提取主要特征 + 防止过拟合。
  • ResNet 的残差连接解决了深层网络退化问题，是里程碑。

14-19. 图像视频的定位与识别

学习目标：理解从图像分类到目标检测/定位的进阶。

核心知识点

  • 图像分类：输出整张图的类别。
  • 目标定位：不仅要分类，还要框出目标位置（Bounding Box）。
  • 目标检测：一张图多个目标，同时分类 + 定位。
  • 经典算法演进：R-CNN → Fast R-CNN → Faster R-CNN → YOLO / SSD。

记忆要点

  • 检测 = 分类 + 定位；两阶段（R-CNN 系列）精度高、速度慢，单阶段（YOLO）速度快、适合实时。

第四部分 · 循环神经网络 RNN

20. 循环神经网络 RNN

学习目标：理解处理序列数据的神经网络。

核心知识点

  • 核心思想：网络具有"记忆"，当前输出不仅依赖当前输入，还依赖历史状态。
  • 结构：隐藏状态 h_t 在时间步之间传递，权值在所有时间步共享。
  • 问题：梯度消失 / 梯度爆炸，难以处理长序列。
  • 改进：LSTM（长短期记忆）、GRU（门控循环单元），通过门控机制缓解梯度消失。

记忆要点

  • RNN 适合处理文本、语音、时间序列等有顺序的数据。
  • LSTM 引入"细胞状态 + 遗忘门/输入门/输出门"，是 RNN 最常用的变体。

第五部分 · 自然语言处理 NLP

21. 什么是自然语言处理

学习目标：建立 NLP 的整体认知。

核心知识点

  • NLP（Natural Language Processing）：让计算机理解、处理、生成人类语言。
  • 两大层次：自然语言理解（NLU）与自然语言生成（NLG）。
  • 典型任务：分词、词性标注、命名实体识别、机器翻译、情感分析、问答、对话系统。

记忆要点

  • NLP 是 AI 皇冠上的明珠，理解语言需要语法 + 语义 + 语用的层层递进。

22. 语言模型

学习目标：理解语言模型的核心概念。

核心知识点

  • 语言模型：计算一个句子出现概率的模型，P(w1, w2, ..., wn)。
  • N-gram 模型：假设当前词只依赖前 N-1 个词。
  • 评价指标：困惑度（Perplexity），越小越好。

记忆要点

  • 语言模型是 NLP 的基石，从 N-gram 到神经语言模型再到如今的大语言模型（LLM）。

23. 语料库和语言知识库

学习目标：了解 NLP 的数据与知识基础。

核心知识点

  • 语料库：真实文本的集合，是训练 NLP 模型的数据来源。
  • 语言知识库：结构化语言知识，如 WordNet（英文）、HowNet（知网）。
  • 标注规范：分词、词性、命名实体等的标注标准。

记忆要点

  • 数据是 NLP 的血肉，语料库质量直接影响模型效果。

24. 词法分析

学习目标：掌握分词与词性标注。

核心知识点

  • 中文分词：中文词间无空格，分词是第一步。方法：基于词典、基于统计（HMM/CRF）、基于深度学习。
  • 词性标注（POS Tagging）：给每个词标注词性（名词、动词等）。
  • 命名实体识别（NER）：识别人名、地名、机构名等实体。

记忆要点

  • 分词错误会级联影响后续所有任务，是中文 NLP 的关键基础步骤。

25. 句法分析

学习目标：理解句子的语法结构。

核心知识点

  • 句法分析：分析句子的语法结构，确定词之间的依存关系。
  • 两类：依存句法分析（Dependency Parsing）与成分句法分析（Constituency Parsing）。

记忆要点

  • 句法分析揭示"谁修饰谁"的结构关系，是深层语义理解的基础。

26. 语义分析

学习目标：理解句子的含义。

核心知识点

  • 语义分析：从"词义"到"句义"到"篇章义"。
  • 词义消歧（WSD）：确定多义词在语境中的具体含义。
  • 语义角色标注（SRL）：标注"谁对谁做了什么"。

记忆要点

  • 语义分析比句法分析更难，是 NLP 从"形式"走向"意义"的关键一步。

27. 语言模型复习

学习目标：巩固语言模型知识。

核心知识点

  • 回顾 N-gram 的统计思想、平滑技术（加一平滑、Kneser-Ney 等）。
  • 理解概率估计中的数据稀疏问题及解决方法。

记忆要点

  • 平滑技术解决 N-gram 中大量零概率事件，是统计语言模型的必要手段。

28. 词向量

学习目标：掌握词的分布式表示。

核心知识点

  • 词向量（Word Embedding）：把词映射到低维稠密向量，语义相近的词向量相近。
  • Word2Vec：CBOW（用上下文预测中心词）与 Skip-gram（用中心词预测上下文）。
  • 经典特性：king - man + woman ≈ queen，向量可做语义运算。

记忆要点

  • 词向量是"分布式语义"的核心，是深度 NLP 的基础，替代了 one-hot 稀疏表示。

29. 词向量案例

学习目标：动手实践词向量。

核心知识点

  • 用 Gensim 训练 Word2Vec 模型。
  • 计算词相似度、找近义词、做向量运算。
from gensim.models import Word2Vec
model = Word2Vec(sentences, vector_size=100, window=5, min_count=1)
model.wv.most_similar('king')

记忆要点

  • 词向量质量取决于语料规模与质量，越大越好。

30. 文本分类

学习目标：掌握文本分类的完整流程。

核心知识点

  • 流程：预处理 → 特征表示（词袋/TF-IDF/词向量）→ 分类器（朴素贝叶斯/SVM/神经网络）。
  • TF-IDF：衡量词对文档的重要性，TF × IDF。
  • 应用：垃圾邮件识别、情感分析、新闻分类、意图识别。

记忆要点

  • TF-IDF 抑制常见词（如"的""是"），突出关键主题词。

31. 机器翻译

学习目标：理解机器翻译的发展脉络。

核心知识点

  • 演进：基于规则 → 统计机器翻译（SMT）→ 神经机器翻译（NMT）。
  • NMT 核心：Seq2Seq 模型 + 注意力机制（Attention）。
  • 评价指标：BLEU 值。

记忆要点

  • Attention 让模型在翻译时"关注"源句的相关部分，是 NMT 的关键突破，也是 Transformer 的基石。

32. 信息抽取

学习目标：从非结构化文本中抽取结构化信息。

核心知识点

  • 信息抽取：从文本中抽取实体、关系、事件等结构化信息。
  • 子任务：命名实体识别（NER）、关系抽取、事件抽取。

记忆要点

  • 信息抽取把"自由文本"变成"结构化数据"，是知识图谱构建的基础。

33. 篇章分析

学习目标：理解篇章级别的语言处理。

核心知识点

  • 篇章分析：处理句子之间的关系（指代、衔接、连贯）。
  • 指代消解（Coreference Resolution）：确定代词指向哪个实体。

记忆要点

  • 篇章分析关注"句子之间"，是理解完整文本语义的必要环节。

34. 问答系统

学习目标：理解问答系统的类型与实现。

核心知识点

  • 问答系统（QA）：根据问题给出准确答案。
  • 类型：基于知识库的 QA、基于文档检索的 QA、生成式 QA。
  • 检索式流程：问题理解 → 检索 → 答案抽取/生成。

记忆要点

  • 问答系统是 NLP 的综合应用，融合了检索、理解、生成多种能力。

第六部分 · 生成对抗网络 GAN

35. 生成对抗网络 GAN

学习目标：理解对抗生成的核心思想。

核心知识点

  • GAN 结构：生成器（Generator）与判别器（Discriminator）的博弈。
  • 生成器：从随机噪声生成"假数据"，目标是骗过判别器。
  • 判别器：区分真假数据，目标是识破生成器。
  • 训练：两者交替优化，最终生成器生成以假乱真的数据。

记忆要点

  • GAN 是"对抗博弈"：生成器越强，判别器越难，反之亦然，最终达到纳什均衡。
  • 应用：图像生成、超分辨率、风格迁移、数据增强。

第七部分 · 强化学习 RL

36. 为何学习强化学习

学习目标：理解强化学习的定位与应用。

核心知识点

  • 强化学习（RL）：智能体（Agent）通过与环境交互、试错，学习最优策略以最大化累计奖励。
  • 与监督学习区别：无标签，通过"奖励信号"学习；决策是序列化的。
  • 应用：游戏（AlphaGo）、机器人、自动驾驶、推荐系统。

记忆要点

  • RL 的核心是"试错 + 奖励反馈"，适合序列决策问题。

37. 马尔科夫决策过程（MDP）

学习目标：掌握 RL 的数学建模框架。

核心知识点

  • MDP 五元组：(S, A, P, R, γ)：状态、动作、转移概率、奖励、折扣因子。
  • 马尔科夫性：下一状态只依赖当前状态和动作，与历史无关。
  • 策略（Policy）：π(a|s)，在状态 s 下选择动作 a 的概率。

记忆要点

  • MDP 是强化学习的理论基础，几乎一切 RL 问题都可建模为 MDP。

38. 动态规划（DP）

学习目标：理解模型已知时的求解方法。

核心知识点

  • 动态规划：在 MDP 完全已知（知道 P 和 R）时求解最优策略。
  • 策略评估：计算给定策略的价值函数。
  • 策略迭代 / 价值迭代：交替或迭代地改进策略，直到收敛到最优。

记忆要点

  • DP 需要完整的模型信息，现实问题往往不知道 P 和 R，因此催生了免模型方法。

39. 蒙特卡罗（MC）

学习目标：理解免模型的价值估计方法。

核心知识点

  • 蒙特卡罗方法：不依赖模型，通过采样完整轨迹（Episode）来估计价值。
  • 核心思想：用大量随机样本的经验平均逼近期望。
  • 特点：必须等一个回合结束才能更新。

记忆要点

  • MC 用"经验平均"替代"期望计算"，是无模型 RL 的基础方法之一。

40. 时间差分方法（TD）

学习目标：掌握 RL 最核心的 TD 学习。

核心知识点

  • TD（Temporal Difference）：结合 MC 的采样与 DP 的自举（Bootstrap）。
  • 核心公式：V(s) ← V(s) + α [R + γV(s') - V(s)]。
  • 优势：无需等回合结束，单步即可更新，方差小。

记忆要点

  • TD 是 MC 和 DP 的结合，是强化学习的核心思想，Sarsa 和 Q-Learning 都基于 TD。

41. 多步时间差分方法

学习目标：理解 TD(λ) 与多步更新。

核心知识点

  • 多步 TD：介于单步 TD 和 MC 之间，用 n 步回报更新。
  • TD(λ)：用 λ 对所有 n 步回报做加权平均，统一了 MC 与 TD。

记忆要点

  • λ 是一个权衡参数：λ=0 是单步 TD，λ=1 是 MC，中间是二者的折中。

42. 值函数逼近

学习目标：解决状态空间过大时的价值估计。

核心知识点

  • 值函数逼近：当状态/动作空间巨大或连续时，用函数（如神经网络）近似价值函数。
  • Deep Q-Network（DQN）：用深度神经网络逼近 Q 值，配合经验回放与目标网络。

记忆要点

  • 值函数逼近让 RL 能处理高维状态（如图像），是深度强化学习的开端。

43. 策略函数逼近

学习目标：掌握直接优化策略的方法。

核心知识点

  • 策略梯度（Policy Gradient）：直接参数化策略，沿"提升期望奖励"的方向更新。
  • Actor-Critic：结合值函数（Critic）与策略（Actor），兼顾稳定与高效。

记忆要点

  • 策略方法适合连续动作空间，值方法适合离散动作空间，Actor-Critic 是两者的结合。

44. 整合学习与规划

学习目标：理解 RL 的整合与前沿方向。

核心知识点

  • 整合学习与规划：结合"从经验学习"与"用模型规划"。
  • Dyna 架构：从真实经验学模型，再用模型生成模拟经验来规划。
  • 前沿方向：深度强化学习、多智能体强化学习、元学习。

记忆要点

  • 学习（Learning）与规划（Planning）结合，能大幅提升样本效率。

第八部分 · 深度学习数学推导

45. 深度学习课程介绍

学习目标：了解本模块的学习目标与路线。

核心知识点

  • 本模块聚焦深度学习的数学基础：逻辑回归、梯度下降、反向传播、向量化。
  • 目标是理解深度学习"为什么能work"，而不只是调用框架。

记忆要点

  • 掌握数学推导，才能真正理解神经网络，而非"调包侠"。

46-47. 深度学习介绍

学习目标：建立对深度学习的整体认识。

核心知识点

  • 深度学习：多层神经网络的机器学习，自动学习数据的层次化特征表示。
  • 发展历程：感知机 → 神经网络 → 深度学习（得益于大数据 + 算力 + 算法）。
  • 应用：图像、语音、文本、游戏等几乎所有 AI 领域。

记忆要点

  • 深度学习的本质是"用多层非线性变换，自动提取从低级到高级的特征"。

48-49. 逻辑回归介绍与损失函数

学习目标：理解逻辑回归的数学原理。

核心知识点

  • 逻辑回归：ŷ = σ(w^T x + b)，用 sigmoid 输出概率。
  • 损失函数：交叉熵损失。

<br /> L(\hat{y}, y) = -[y \log \hat{y} + (1-y)\log(1-\hat{y})]<br />

  • 为什么不用 MSE：MSE 在 sigmoid 下是非凸的，易陷入局部最优；交叉熵是凸的，且梯度更合理。

记忆要点

  • 交叉熵损失是分类问题的标准选择，它惩罚"自信的错误"。

50. 梯度下降算法过程以及公式

学习目标：理解梯度下降的迭代优化思想。

核心知识点

  • 梯度下降：沿损失函数梯度的反方向更新参数，逐步逼近最小值。

<br /> w := w - \alpha \frac{\partial L}{\partial w}<br />

  • 学习率 α：控制步长，太大震荡、太小收敛慢。
  • 变体：批量（BGD）、随机（SGD）、小批量（Mini-batch）梯度下降。

记忆要点

  • 梯度指向函数增长最快的方向，反方向下降最快，这就是"梯度下降"。

51-53. 导数与链式法则

学习目标：掌握反向传播的数学基础。

核心知识点

  • 导数：函数在某点的变化率，f'(x) = lim (f(x+h)-f(x))/h。
  • 计算图（Computational Graph）：把复杂函数拆成基本运算的图结构。
  • 链式法则（Chain Rule）：dz/dx = dz/dy × dy/dx，是反向传播的核心。

记忆要点

  • 反向传播本质就是链式法则在计算图上的高效应用，从输出到输入逐层求导。

54. 逻辑回归的导数计算图分析

学习目标：把逻辑回归的求导用计算图表示。

核心知识点

  • 画出逻辑回归的计算图：x → z=w^T x+b → a=σ(z) → L(a,y)。
  • 逐层用链式法则求 ∂L/∂w 和 ∂L/∂b。
  • 关键中间导数：∂L/∂z = a - y（这个简洁结果非常重要）。

记忆要点

  • 逻辑回归反向传播中，∂L/∂z = a - y 是个漂亮的结果，记忆它可快速推导。

55-57. 向量化编程

学习目标：掌握向量化提升训练效率。

核心知识点

  • 向量化：用矩阵运算替代 for 循环，一次处理多个样本。
  • 优势：利用 SIMD 指令与高度优化的 BLAS 库，速度提升几十到几百倍。
  • 实现：把多个样本堆叠成矩阵 X，一次性前向 + 反向传播。
Z = np.dot(W, X) + b   # 向量化：一次算所有样本
A = sigmoid(Z)
dZ = A - Y
dW = np.dot(dZ, X.T) / m

记忆要点

  • 深度学习中能向量化就向量化，for 循环是大忌，性能差异巨大。

58. 正向传播与反向传播

学习目标：理解神经网络训练的完整流程。

核心知识点

  • 正向传播（Forward Propagation）：输入 → 逐层计算 → 输出预测。
  • 反向传播（Backpropagation）：从损失出发，逐层计算梯度，更新参数。
  • 训练 = 反复"前向 + 反向"，直到损失收敛。

记忆要点

  • 前向传播"算结果"，反向传播"算梯度"，二者交替完成一次参数更新。

59-63. 作业讲解（构建神经网络）

学习目标：动手实现一个完整的神经网络。

核心知识点

  • 实现步骤：
    1. 实现 sigmoid 激活函数及其导数
    2. 构建单神经元模型（逻辑回归）
    3. 参数初始化
    4. 前向传播计算损失
    5. 反向传播计算梯度
    6. 梯度下降更新参数
    7. 迭代训练直至收敛
def sigmoid(z):
    return 1 / (1 + np.exp(-z))

def initialize(dim):
    w = np.zeros((dim, 1))
    b = 0
    return w, b

def propagate(w, b, X, Y):
    m = X.shape[1]
    A = sigmoid(np.dot(w.T, X) + b)
    cost = -np.sum(Y*np.log(A) + (1-Y)*np.log(1-A)) / m
    dw = np.dot(X, (A-Y).T) / m
    db = np.sum(A-Y) / m
    return dw, db, cost

记忆要点

  • 手写一遍神经网络，才能真正理解"前向 + 反向 + 梯度下降"的完整闭环。

64-67. 浅层神经网络

学习目标：从单神经元进阶到多层网络。

核心知识点

  • 浅层神经网络：含一个隐藏层的神经网络，可表示更复杂的非线性函数。
  • 前向传播：Z¹ = W¹X + b¹ → A¹ = g(Z¹) → Z² = W²A¹ + b² → ŷ = σ(Z²)。
  • 激活函数选择：隐藏层常用 tanh 或 ReLU，输出层二分类用 sigmoid。
激活函数 公式 特点
sigmoid 1/(1+e^-z) 输出 (0,1)，易梯度消失
tanh (e^z-e^-z)/(e^z+e^-z) 输出 (-1,1)，优于 sigmoid
ReLU max(0,z) 计算快，缓解梯度消失

记忆要点

  • 隐藏层不能用线性激活，否则多层等价于单层；非线性激活是深度网络表达力的来源。

68-72. 作业实现与总结

学习目标：完整实现浅层神经网络并总结。

核心知识点

  • 完整实现：初始化 → 前向 → 计算损失 → 反向 → 更新 → 迭代。
  • 超参数：学习率、隐藏层大小、迭代次数需反复调优。
  • 总结：深度学习 = 数据 + 模型 + 损失函数 + 优化算法 的有机结合。

记忆要点

  • 一个完整神经网络的训练，本质是"梯度下降在参数空间里寻优"的过程。
