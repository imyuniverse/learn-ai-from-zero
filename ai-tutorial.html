第 0 章 · 怎么学，以及学之前你需要知道的事

0.1 先给你打一针"防焦虑针"

很多人学 AI 半途而废，不是不够聪明，而是路径错了：

  • ❌ 一上来就看"Transformer 详解"，被注意力矩阵吓退；
  • ❌ 盲目收藏 100 个教程，一个都没看完；
  • ❌ 纠结"该学 PyTorch 还是 TensorFlow"，结果两个都没学。

正确的路径其实只有一条：

先学「能跑通的最小闭环」，再逐层往下挖原理。

也就是说，你先要能写出一个"读数据 → 训练 → 预测"的完整小程序，哪怕它只是个线性回归。有了这个闭环，后面所有东西都是往这个骨架上添砖加瓦。

0.2 学习路线总览

第 1 阶段（2-3 周）  Python + NumPy          → 会用工具
第 2 阶段（2-3 周）  数学基础 + 机器学习入门   → 理解"学习"是什么
第 3 阶段（3-4 周）  神经网络 + PyTorch       → 现代 AI 的地基
第 4 阶段（4-6 周）  Transformer + LLM        → 触达前沿
第 5 阶段（持续）    多模态 / Agent / 项目实战  → 做出作品

每个阶段结束都有一个「里程碑项目」，做出来你会有强烈的正反馈。

第 1 章 · Python 上手：你的第一门语言

1.1 为什么是 Python

AI 领域 90% 的代码是 Python 写的。它语法简单、生态成熟（NumPy、PyTorch、Hugging Face 都在 Python 上）。你不需要先学 C++。

1.2 基础语法速览

1.3 NumPy：AI 的算盘

NumPy 提供了 ndarray（多维数组），它是所有 AI 库的数据基础。

import numpy as np

a = np.array([1, 2, 3, 4])
b = np.array([[1, 2], [3, 4]])   # 2x2 矩阵

print(a.shape)    # (4,)
print(b.shape)    # (2, 2)

# 向量化运算：不需要 for 循环
print(a * 2)          # [2 4 6 8]
print(a + a)          # [2 4 6 8]

# 矩阵乘法 @  vs  逐元素乘法 *
c = np.dot(b, b)      # 矩阵乘法
d = b * b             # 逐元素相乘
print(c)

为什么向量化重要？ 因为 GPU 擅长"同时做很多一样的运算"。向量化让代码能被硬件并行加速。这一章你只需要记住：能用 NumPy 数组运算，就别写 for 循环。

第 2 章 · 数学准备：够用就好，别吓自己

很多人卡在数学上。我的建议是：先建立直觉，公式能读懂即可，推导留到需要时再补。 这一章只讲三个你绕不开的数学块。

2.1 线性代数：数据就是"向量和矩阵"

  • 向量：一串数字，比如一张灰度图可以是一个 784 维向量。
  • 矩阵：多行多列的数字，一个 batch 的数据就是矩阵。
  • 矩阵乘法：神经网络每一层本质就是一次"矩阵乘法 + 非线性变换"。

直觉：矩阵乘法 W @ x 就是"对输入 x 做一次线性组合"，把信息从一种表示变换成另一种表示。

2.2 微积分：模型"学习"的引擎

  • 导数 = 变化率：函数在某点上升/下降多快。
  • 梯度 = 多维的导数：指向函数增长最快的方向。
  • 梯度下降：沿着梯度反方向走，就能到达最小值。

一句话记住：训练神经网络 = 反复用梯度下降调整参数，让"预测误差"越来越小。 这就是第 5 章要展开的全部。

2.3 概率：面对不确定性的语言

  • 概率分布：描述随机变量的取值可能性。
  • 条件概率：P(A|B)，已知 B 发生时 A 的概率。
  • 似然：给定参数，数据出现的概率——机器学习的很多损失函数本质上就是"最大化似然"。

2.4 动手任务

用 Python 画出 y = x² 的图像，并计算它在 x=3 处的导数（手动算 + 用代码验证）。你不需要记公式，但要知道"导数长这样"。

第 3 章 · 机器学习入门：让机器从数据里"学"

3.1 机器学习到底是什么

传统编程：人写规则 → 输入 → 输出。 机器学习：人给数据 → 算法自动学出规则 → 输出。

经典例子：识别手写数字。你不会写几百条 if-else 判断"这个像素是 0 还是 1"，而是给模型几千张标注好的图片，让它自己找规律。

3.2 三大范式

范式 数据 目标 例子
监督学习 有标签 预测标签 房价预测、垃圾邮件识别
无监督学习 无标签 发现结构 聚类、降维
强化学习 奖励信号 学最优策略 游戏 AI、机器人

3.3 你的第一个模型：线性回归

用一条直线拟合数据点。

from sklearn.linear_model import LinearRegression
import numpy as np

# 假设：学习时间 → 考试成绩
X = np.array([[1], [2], [3], [4], [5]])   # 学习小时数
y = np.array([55, 60, 68, 75, 82])        # 分数

model = LinearRegression()
model.fit(X, y)

print("斜率:", model.coef_[0])   # 每多学 1 小时，分数涨多少
print("预测学 6 小时:", model.predict([[6]])[0])

这就是"机器学习"的最小完整闭环：有数据、有模型、有训练（fit）、有预测（predict）。后面所有复杂模型，本质上都在重复这四步。

3.4 判断模型好坏：过拟合与欠拟合

  • 欠拟合：模型太简单，训练集和测试集都表现差。
  • 过拟合：模型太复杂，训练集满分、测试集很差——它"背"了数据而不是"学"了规律。
  • 目标：在两者之间找到平衡。

评估指标（分类问题）：

  • 准确率：预测对的比例（但类别不平衡时会骗人）。
  • 精确率 / 召回率 / F1：分别回答"预测为正的里有多少真"、"真的正类里抓到多少"、"两者的调和平均"。

3.5 动手任务

用 sklearn 加载经典的鸢尾花数据集，训练一个分类器，打印准确率，并理解训练集/测试集为什么要分开。

from sklearn.datasets import load_iris

第 4 章 · 经典机器学习算法：一张地图

这一章给你一张"算法地图"，重点是知道什么算法解决什么问题，而不是背公式。深度学习（第 5 章起）虽强，但这些经典方法在很多场景依然又快又好用。

4.1 决策树与随机森林

  • 决策树：用一连串 if-else 规则做判断，可解释性强（你能看到"为什么这么判"）。
  • 随机森林：种很多棵"不同的"树，投票决定结果，稳定抗过拟合。
  • 用途：表格数据的分类/回归，金融风控、医疗诊断常用。

4.2 支持向量机 SVM

  • 找一个"间隔最大"的分界线，把两类分得越开越好。
  • 优点：小样本、高维数据表现好。
  • 注意：要先把特征标准化。

4.3 聚类（K-Means）

  • 无监督：把样本自动分成 K 组，组内相似、组间不同。
  • 用途：用户分群、图像压缩、异常检测。

4.4 降维（PCA）

  • 把高维数据压缩到低维，保留主要信息。
  • 用途：可视化、去噪、加速计算。

4.5 一张速查表

问题类型 首选的经典方法 现代替代
表格分类/回归 随机森林、XGBoost 深度网络
小样本分类 SVM —
无标签分群 K-Means 自编码器
高维可视化 PCA t-SNE、UMAP

🔭 最新进展：即使是 2026 年，表格数据任务（Tabular）依然是 XGBoost、LightGBM 这类梯度提升树的天下，深度学习并未完全取代它们。这是你面试/竞赛里很有用的一个认知。

第 5 章 · 神经网络与反向传播：现代 AI 的地基

这是整个教程最核心的一章。理解了这一章，你就理解了深度学习 80% 的本质。 慢一点，值得。

5.1 从"感知机"到"神经网络"

一个神经元做的事极其简单：

输出 = 激活函数( 权重·输入 + 偏置 )
      即  y = σ(w₁x₁ + w₂x₂ + ... + b)

把很多个这样的神经元分层叠起来，就是神经网络。层与层之间全是"线性变换 + 非线性激活"。

关键问题：为什么要非线性激活？ 因为如果全是线性，多层网络等价于一层（矩阵乘法可合并），就无法拟合曲线。非线性激活（如 ReLU）给了网络"弯曲"的能力。

5.2 前向传播：从输入算出预测

以两层网络为例：

Z¹ = W¹X + b¹        # 第一层线性变换
A¹ = ReLU(Z¹)        # 非线性激活
Z² = W²A¹ + b²       # 第二层线性变换
ŷ  = sigmoid(Z²)     # 输出概率

5.3 损失函数：量化"错得有多离谱"

  • 回归用 均方误差 MSE。
  • 二分类用 交叉熵：L = -[y·log(ŷ) + (1-y)·log(1-ŷ)]。

损失越小，模型越好。训练的目标就是最小化损失。

5.4 反向传播：怎么知道每个参数该调多少

这是神经网络能"学习"的关键。核心思想只有一条：

链式法则。误差对每一层参数的梯度，从输出层一路"往回传"，逐层算出每个参数该怎么调。

想象一个多米诺骨牌：最后一排倒了（输出错），你想知道是哪块牌（参数）的锅，就从后往前一级级追溯影响。反向传播做的就是这个"追溯"，只不过它追的是数学上的"梯度"。

5.5 从零手写一个神经网络（建议亲手敲一遍）

import numpy as np

def sigmoid(z):
    return 1 / (1 + np.exp(-z))

# 一个逻辑回归（单神经元）的完整训练
np.random.seed(0)
X = np.random.randn(2, 100)              # 2 个特征，100 个样本
y = (X[0] + X[1] > 0).astype(int).reshape(1, 100)  # 标签

w = np.random.randn(2, 1) * 0.01
b = 0.0
lr = 0.1

for i in range(1000):
    # 前向传播
    z = w.T @ X + b
    a = sigmoid(z)
    # 损失（交叉熵）
    loss = -np.mean(y * np.log(a + 1e-8) + (1 - y) * np.log(1 - a + 1e-8))
    # 反向传播（梯度）
    dz = a - y
    dw = X @ dz.T / 100
    db = np.mean(dz)
    # 梯度下降更新
    w -= lr * dw
    b -= lr * db
    if i % 100 == 0:
        print(f"step {i}, loss = {loss:.4f}")

print("训练完成，最终权重:", w.ravel())

观察：loss 从接近 0.69 一路下降。这就是"机器在学习"的全部真相——反复"前向算损失 + 反向算梯度 + 更新参数"。

🔭 最新进展：你刚手写的这套"前向+反向+梯度下降"，正是 GPT、扩散模型等一切深度模型的共同底层。差别只在网络结构更大、数据更多。理解了它，你就没有"神秘感"了。

第 6 章 · PyTorch 实战：把纸上的网络变成真模型

上一章你手写网络是为了"懂原理"。工程上我们不会手写，而是用 PyTorch（2026 年 AI 研究和工业界最主流的框架）。

6.1 核心三件套：张量、自动微分、模块

import torch

# 1. 张量（Tensor）：PyTorch 版的 NumPy 数组，但能在 GPU 上跑
x = torch.tensor([[1., 2.], [3., 4.]], requires_grad=True)  # requires_grad 开启求导

# 2. 自动微分：PyTorch 帮你算梯度（不需要手写反向传播了！）
y = (x ** 2).sum()
y.backward()
print(x.grad)   # 自动算出 dy/dx

这就是 PyTorch 最大的价值：你只需写"前向传播"，反向传播（梯度）由框架自动计算。第 5 章你手推的链式法则，这里一行 backward() 就搞定。

6.2 用 nn.Module 搭网络

import torch.nn as nn

class Net(nn.Module):
    def __init__(self):
        super().__init__()
        self.fc1 = nn.Linear(2, 8)    # 输入2 → 隐藏8
        self.fc2 = nn.Linear(8, 1)    # 隐藏8 → 输出1

    def forward(self, x):
        x = torch.relu(self.fc1(x))
        x = torch.sigmoid(self.fc2(x))
        return x

model = Net()
print(model)

6.3 标准训练循环（背下来，处处通用）

import torch.optim as optim

criterion = nn.BCELoss()          # 二分类交叉熵
optimizer = optim.Adam(model.parameters(), lr=0.01)

for epoch in range(100):
    # 前向
    pred = model(X)
    loss = criterion(pred, y)
    # 反向 + 更新
    optimizer.zero_grad()   # 清空上一轮梯度
    loss.backward()         # 自动求梯度
    optimizer.step()        # 更新参数

这个循环（zero_grad → backward → step）是 PyTorch 训练的"咒语"，你会在无数项目里看到它。

6.4 动手任务

用 PyTorch 重写第 5 章的逻辑回归，跑通上面这个训练循环，打印 loss 下降曲线。你会发现：代码更短，但做的事一模一样。

第 7 章 · 深度学习架构：CNN 与 RNN

7.1 CNN：让计算机"看懂"图像

普通全连接网络处理图像有两个致命问题：参数量爆炸 + 丢失空间结构。

CNN 的三大绝招：

  1. 卷积：用一个小滤波器在图上滑动，提取局部特征（边缘、纹理）。
  2. 权值共享：同一个滤波器扫全图，参数骤减。
  3. 池化：缩小尺寸、增强鲁棒性。
import torch.nn as nn

class CNN(nn.Module):
    def __init__(self):
        super().__init__()
        self.conv = nn.Sequential(
            nn.Conv2d(1, 16, kernel_size=3),   # 1通道 → 16通道
            nn.ReLU(),
            nn.MaxPool2d(2),
            nn.Conv2d(16, 32, kernel_size=3),
            nn.ReLU(),
            nn.MaxPool2d(2),
        )
        self.fc = nn.Linear(32 * 5 * 5, 10)     # 假设输入28x28

    def forward(self, x):
        x = self.conv(x)
        x = x.view(x.size(0), -1)               # 展平
        return self.fc(x)

🔭 最新进展：CNN 之后，Vision Transformer (ViT) 把图像切成 patch、当"词"喂给 Transformer，在很多任务上超越了 CNN。但 CNN 依然高效、省数据，是入门和工业界的常青树。

7.2 RNN 与 LSTM：处理"序列"

语言、语音、时间序列都是有序的。RNN 的核心是"记忆"——当前输出不仅看当前输入，还看历史。

RNN 的痛点：长序列会梯度消失（记不住太早的信息）。

LSTM 用"门控"解决：遗忘门（忘掉不重要的）、输入门（记下新的）、输出门（输出有用的），让信息能跨越长距离传递。

🔭 最新进展：2017 年 Transformer 出来后，RNN/LSTM 在 NLP 主流任务中被大量取代（因为 Transformer 能并行、能建模任意长依赖）。但 LSTM 在时间序列预测、语音等领域依然活跃。理解它是理解 Transformer"为什么更好"的铺垫。

第 8 章 · Transformer 与注意力机制：现代 AI 的核心

这是通往大模型（GPT、Claude、Gemini）的必经之路。 搞懂注意力，你就搞懂了现代 AI 的引擎。

8.1 先理解"注意力"的直觉

翻译一句话："The animal didn't cross the street because it was too tired."

这里 "it" 指谁？指 "animal"。人脑会自动"注意"到前面相关的词。

注意力机制就是让模型也这样做：在生成每个输出时，学会"该重点关注输入的哪些部分"。

8.2 Self-Attention：每个词都看所有词

核心公式：

Attention(Q, K, V) = softmax( Q·Kᵀ / √d ) · V

直觉拆解：

  1. Q（查询）：我现在想找什么。
  2. K（键）：每个词"是什么"。
  3. Q·Kᵀ：计算"我和每个词有多相关" → 得到一个注意力分数矩阵。
  4. softmax：把分数归一化成权重（加起来等于 1）。
  5. × V（值）：按权重加权求和，得到"融合了全局信息的新表示"。

一句话：Self-Attention 让每个词根据"与所有词的相似度"来重新编码自己。

8.3 Transformer = 堆叠的注意力 + 前馈网络

Transformer 的两大模块：

  • 多头注意力（Multi-Head Attention）：多组注意力并行，捕捉不同角度的关系。
  • 前馈网络（FFN）：每个位置独立做非线性变换。

再加上 位置编码（因为注意力本身不关心顺序）、残差连接、层归一化，就组成了完整的 Transformer 块。GPT 就是把这些块堆很多层、喂海量文本训练出来的。

8.4 动手任务

不要求你从零实现 Transformer（那是进阶），但建议：

  1. 读一遍 PyTorch 官方 nn.Transformer 的文档和一个小例子。
  2. 用 torch.nn.MultiheadAttention 跑一个最小 demo，打印注意力权重，直观感受"词与词的相关性"。

🔭 最新进展：2026 年的前沿已经超越经典 Transformer—— - 稀疏 MoE（混合专家）：不是所有参数都激活，一次推理只唤醒一部分"专家"，如 Yuan 3.0 Flash、MiniMax-M2.1-PRISM，用更少算力达到更强智能。 - 递归语言模型（RLM）：让模型把"自己的 prompt 当可操作对象"，通过代码反复调用自己来推理，被视为 2026 年的新范式。 - 扩散模型推理（DiffThinker）：把多模态推理"图像到图像"地用扩散模型做，在视觉谜题上超过 GPT-5 300%。这些都在提醒你：Transformer 是起点，不是终点。

第 9 章 · 大语言模型 LLM：如何"玩转"而不是"畏惧"

9.1 GPT 到底在做什么

一句话：GPT 是一个"预测下一个词"的超级模型。 给它一段前缀，它输出最可能的下一个词，然后把这个词接上去，再预测下一个……如此反复，就"生成"了整段话。

这个简单的机制，配合海量数据 + 巨大模型 + 强化学习对齐（RLHF），就涌现出了回答问题、写代码、推理等能力。

9.2 从"用"到"懂"的三个层次

层次 你在做什么 需要什么
用 调 API / 用 ChatGPT 无
调 Prompt 工程、RAG、微调 少量代码
训 自己预训练/对齐模型 大量算力（先别碰）

对 CUHK 大一同学，先到"调"这一层就非常强了。

9.3 Prompt 工程：和模型"好好说话"

核心技巧：

  • 给角色："你是一名资深算法工程师……"
  • 给示例（Few-shot）：给一两个输入输出样例，模型照着学。
  • 给约束："分三步回答""用中文""只输出代码"。
  • 让模型思考（Chain-of-Thought）："请一步步推理，不要直接给答案"。

9.4 RAG：让模型"知道你的资料"

大模型有知识截止日期，也不知道你的私有文档。RAG（检索增强生成） 的做法：

  1. 把你的文档切块、转成向量（Embedding）存进向量数据库。
  2. 用户提问时，先检索最相关的几块。
  3. 把这些内容塞进 prompt，让模型基于它们回答。

这是 2026 年企业 AI 应用最主流的落地方式，非常值得你做一个 demo。

9.5 动手任务（选一个）

  1. 用 OpenAI / 任一国产大模型的 API，写一个"你的私人学习助手"命令行脚本。
  2. 用 langchain 或 llama_index 搭一个最小 RAG：喂进去你的课程笔记，然后向它提问。

🔭 最新进展：2026 年 LLM 的关键词是 Agent（智能体） 和 端侧化—— - Agent 不再只是"一问一答"，而是能规划、调用工具、自我纠错地完成长任务（如 Claude Code、OpenAI Operator）。 - 端侧模型（Apple 20B 稀疏 MoE、Gemini Nano）让"不联网也能跑大模型"成为现实。 你在第 11 章会系统了解 Agent。

第 10 章 · 多模态与生成模型：AI 也能"画"和"听"

10.1 生成模型的思想转变

之前的模型都在"判别"（这是猫还是狗）。生成模型反其道而行：学数据的分布，然后"造"出新的数据。

10.2 GAN：两个网络的博弈

  • 生成器：从噪声造"假图"，目标是骗过判别器。
  • 判别器：分辨真假，目标是识破生成器。
  • 两者对抗训练，生成器越来越强，最终"以假乱真"。

10.3 扩散模型：2026 年生成式 AI 的主流

GAN 曾经辉煌，但扩散模型（Diffusion）成了当前文生图/文生视频的绝对主力（Stable Diffusion、Midjourney、Sora 都是这类）。

核心思想（其实很优雅）：

  1. 前向加噪：给一张真实图一点点加噪声，直到变成纯噪声。
  2. 反向去噪：训练模型学会"从噪声一点点还原出清晰图"。
  3. 生成时：从纯噪声出发，让模型一步步去噪，就"生成"了一张新图。

一句话类比：扩散模型学的是"如何把一张被墨水弄脏的图擦干净"，擦得够好，就能从"全黑"擦出任意想要的图。

10.4 动手任务

用 Hugging Face 的 diffusers 库，在 Colab 上跑一次 Stable Diffusion 文生图（免费 GPU 即可）。感受"一行代码生成图片"的震撼，也顺便学会用 Hugging Face 这个 AI 界的 GitHub。

第 11 章 · 智能体 Agent 与 2026 前沿全景

最后这一章，帮你站在 2026 年的最前沿，看清"接下来该往哪走"。

11.1 什么是 Agent

普通 LLM：你问一句，它答一句，无记忆、无行动能力。

Agent（智能体） = LLM + 记忆 + 工具 + 规划：

  • 规划：把大任务拆成小步骤。
  • 调用工具：能搜索、写代码、调 API、操作浏览器。
  • 自我反思：检查自己做得对不对，不对就重来。

所以 Agent 能独立完成"帮我爬这个网站的数据、分析、写报告"这类长任务。

11.2 一个极简 Agent 的心智模型

循环：
  1. 思考（LLM 生成"下一步做什么"）
  2. 行动（调用某个工具/函数）
  3. 观察（拿到结果）
  4. 反思（结果对吗？还差什么？）
直到任务完成

这个 "Thought-Action-Observation" 循环，就是 ReAct 等主流 Agent 框架的骨架。你可以用几十行 Python + 一个 LLM API 实现它。

11.3 2026 前沿全景（按"和你相关度"排序）

方向 一句话解释 对大一同学的意义
Agent / Agentic Workflow LLM 自主规划+用工具+纠错完成长任务 最值得学的应用方向
稀疏 MoE 架构 一次只激活部分参数，算力换智能 理解大模型为什么"又大又省"
多模态（图文音视频） 模型能看、能听、能生成 AI 应用的默认形态
端侧推理 手机上跑前沿模型 理解隐私与成本的新变量
扩散模型推理 用扩散做"想"而非只做"画" 生成与推理的边界在模糊
递归语言模型 RLM 模型把 prompt 当代码反复调用自己 2026 新范式，值得关注
